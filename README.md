# topchelrobot
Реализация в телеграм. детской игры в сифу, для СОаиД "Боярский"

## Анализ истории
Для восстановления истории побед из JSON-экспорта Telegram используйте скрипт `generate_history.py`:

```bash
python3 generate_history.py --input path/to/result.json
```

Скрипт создаст структуру папок в `data/` с ежемесячной статистикой и информацией о пользователях.

## Статус игроков
Для формирования списка активных и вышедших из игры участников используйте скрипт `check_players_status.py`:

```bash
python3 check_players_status.py --input notebook/result.json
```

Скрипт учитывает возвращение игроков в чат после их временного отсутствия.
